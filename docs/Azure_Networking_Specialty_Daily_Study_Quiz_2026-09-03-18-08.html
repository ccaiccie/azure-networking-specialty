Hybrid connectivity and architecture

ExpressRoute FastPath: data-path bypass with gateway control

FastPath can improve supported on-premises-to-VM flows by bypassing the ExpressRoute gateway data path; the gateway remains part of the connection and route-control design.

Hybrid connectivity and architecture

VPN Gateway active-active resiliency

An active-active VPN gateway runs two active instances with separate public IPs; production S2S designs must form tunnels and, where used, BGP sessions to both instances.

Primary: About active-active VPN gateways
Scenario/case: Design highly available gateway connectivity

Azure Route Server and managed BGP exchange

Core networking infrastructure

VNet address planning and subnet segmentation

Plan unique, non-overlapping CIDR ranges before peering or hybrid connectivity; use subnets to separate responsibilities and reserve required service subnets early.

Primary: Azure Virtual Network overview
Scenario/case: Plan Azure virtual networks

Core networking infrastructure

Standard and Gateway Load Balancer roles

Azure Load Balancer provides Layer 4 TCP/UDP distribution and health probes. Gateway Load Balancer chains supported public endpoints or NICs to insert NVAs transparently, rather than using a UDR next hop.

Primary: Azure Load Balancer overview
Scenario/case: Gateway Load Balancer overview

Core networking infrastructure

Application Gateway v2: Layer 7 routing and WAF

Application Gateway v2 makes HTTP(S) decisions by host or URL path, needs a dedicated subnet, and supports modern scale, zone, and WAF capabilities.

Primary: Azure Application Gateway overview
Scenario/case: Azure Application Gateway v2 overview

Routing and traffic management

System routes, UDRs, BGP propagation, and effective routes

A NIC's effective routes combine Azure system routes, subnet-associated UDRs, and propagated BGP routes; inspect the effective route table before changing a design.

Primary: Azure virtual network traffic routing
Scenario/case: Diagnose a virtual machine routing problem

9

Routing and traffic management

Global web traffic: Front Door versus Traffic Manager

Front Door is a global Layer 7 edge service that routes HTTP(S) requests. Traffic Manager is DNS-based and returns endpoints, so resolver caching affects observed behavior.

Primary: Azure Front Door routing architecture
Scenario/case: Traffic Manager routing methods

Security, monitoring, and private service access

Private Endpoints and private DNS

A private endpoint is a NIC with a private VNet IP. Use approved connections and ensure the service FQDN resolves to that private address, usually through private DNS zones.

Primary: What is a private endpoint?
Scenario/case: Private endpoint DNS integration scenarios

Security, monitoring, and private service access

Azure Firewall, NSGs, and forced-tunnel inspection

Azure Firewall is a managed, stateful service for north-south and east-west inspection. NSGs provide distributed boundaries, while UDRs can steer traffic through a central firewall.

Primary: Azure Firewall overview
Scenario/case: Implement a secure hybrid network

Security, monitoring, and private service access
